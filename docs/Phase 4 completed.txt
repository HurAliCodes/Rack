# 8. VALIDATION MIDDLEWARE

Existing validation middleware is:

```ts
import { NextFunction, Request, Response } from "express";
import { z, ZodObject } from "zod";

export const validate = (schema: ZodObject<any>) => {
  return (req: Request, _res: Response, next: NextFunction) => {
    const result = schema.safeParse({
      body: req.body,
      query: req.query,
      params: req.params,
    });

    if (!result.success) {
      return next(result.error);
    }

    req.body = result.data.body;
    req.query = result.data.query;
    req.params = result.data.params;

    next();
  };
};
```

This is currently working.

Do not replace it unless necessary.

# 14. CLOTHING ITEM

Current model concept:

```prisma
model ClothingItem {
  id String @id @default(uuid())

  name String?

  category ClothingCategory @default(UNKNOWN)

  brand String?

  color String?

  season ClothingSeason?

  size String?

  notes String?

  favorite Boolean @default(false)

  status ClothingStatus @default(AVAILABLE)

  lastWornAt DateTime?

  userId String

  user User @relation(
    fields: [userId],
    references: [id],
    onDelete: Cascade
  )

  images ClothingImage[]

  createdAt DateTime @default(now())

  updatedAt DateTime @updatedAt
}
```

IMPORTANT:

`category` has:

```text
@default(UNKNOWN)
```

This was intentional.

Reason:

A clothing item can be created before AI analyzes the image.

Later AI can detect the category and update it.

Workflow:

```text
Create clothing
      ↓
category = UNKNOWN
      ↓
AI analyzes image
      ↓
AI detects category
      ↓
Update category
```
